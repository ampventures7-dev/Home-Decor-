# Malhar Handcrafted Home Decor

A bespoke, slow-crafted e-commerce experience celebrating Indian artisanal home living, rooted in Ganpatipule, Konkan. Built with React 19, Vite, Tailwind CSS, and Lucide Icons.

---

## ✨ Features

- **Artisanal Design System**: Custom palette (Walnut brown, Terracotta, Warm Beige, Charcoal, and Brass) with serif typography and micro-animations.
- **Interactive Header & Mega-Menu**: Multi-column dropdowns by category (Sofas, Living, Bedroom, Dining, Storage, Decor) with promotional highlight cards.
- **Hero Carousel**: 4-slide animated carousel showcasing signature collections with direct CTA links.
- **Dynamic Catalog & Filtering**:
  - Filter by category, price slider, materials (Seasoned Teak, Natural Cane, Terracotta, Linen, Brass), and finish colors.
  - Responsive product grid (4 columns desktop, 2 columns mobile) with live sorting.
- **Rich Product Detail Pages (PDP)**:
  - Multi-angle gallery showcase (Front view, Angle, Detail joinery, Room context).
  - Cursor-tracking 1.75x magnifying hover zoom.
  - Finish swatches, size selector, pincode delivery checker, and accordion information tabs.
- **Cart & Wishlist**:
  - Real-time quantity steppers, subtotal & free delivery threshold bar.
  - Coupon code support (`MALHAR1000`, `FIRST10`).
  - Interactive multi-step checkout simulation with order confirmation.
- **About Us & Story**: Narrates the heritage of Konkan karigars, workshop processes, and fair craft lineages.
- **Zero Broken Links**: All buttons, links, and forms navigate to live routes or trigger interactive feedback toasts.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/ampventures7-dev/Home-Decor.git
cd Home-Decor
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) (or the port indicated in your terminal).

### 4. Build for production
```bash
npm run build
npm run preview
```
